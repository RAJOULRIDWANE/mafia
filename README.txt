RAJOUL MAFIA - pass-and-play role distributor

OFFLINE ON A PHONE (pick one):
A) Install as an app (best): host this folder once (Netlify Drop / GitHub Pages),
   open the link on the phone, then "Add to Home Screen". Works offline after that.
B) Single file: send RAJOUL-MAFIA-single-file.html to the phone and open it.

Files: index.html, style.css, script.js, icons.js, sw.js, manifest.webmanifest, icons/
Icons: Iconify, Material Design Icons set (mdi), embedded in icons.js.
